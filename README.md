## 🌟 Overview  
Event Planner is a comprehensive **Python-based** application designed to streamline and automate various aspects of event planning. From task management to venue selection, our tool aims to make event organization **efficient and hassle-free**.  

---

## 🚀 Features  
✔ **Task Management** – Create, assign, and track tasks for your event.  
✔ **Crew Management** – Manage your event staff and their responsibilities.  
✔ **Equipment Tracking** – Keep track of catering and general equipment needs.  
✔ **Venue Selection** – Store and manage venue details for easy selection.  
✔ **Marketing Reports** – Generate insightful marketing reports for your events.  
✔ **API Integration** – Utilize our FastAPI-based API for seamless integration with other tools.  

---

## 🛠 Technologies Used  
- **Python**  
- **FastAPI**  
- **JSON** for data storage  
- **Environment Variables** for configuration

## 🏁 Getting Started  

### 🔹 Prerequisites  
Ensure you have the following installed:  
- Python **3.8+**  
- `pip` (Python package manager)  

---

### 🔹 Installation  

1️⃣ **Clone the repository:**  
   ```bash
   git clone https://github.com/saikonda5468/Event-Planner.git
   ```

2️⃣ **Navigate to the project directory:**  
   ```bash
   cd Event-Planner
   ```

3️⃣ **Install required dependencies:**  
   ```bash
   pip install -r requirements.txt
   ```

4️⃣ **Set up environment variables:**  
   - Copy the `.env.example` file to `.env`  
   - Fill in the necessary details in the `.env` file  

---

## 🖥 Usage  

1️⃣ **Start the application:**  
   ```bash
   python app.py
   ```
